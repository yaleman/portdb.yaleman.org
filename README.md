# portDB

Source for [portdb.yaleman.org](https://portdb.yaleman.org), a Zola-built reference for TCP and UDP port numbers.

Install Python dependencies with `uv sync --all-groups`, install Zola 0.23.3 or newer, then run:

```shell
make generate
make check
make serve
```

Edit port notes under `data/<protocol>/<port>/`; `content/` is generated by `make generate`.
